# Фоновые изображения и обои в Телемосте

В `theme.json` можно устанавливать фоновые изображения (обои, паттерны, текстуры) для любых зон и поверхностей интерфейса Телемоста: окна чата, главного экрана, боковой панели со списком чатов, экрана звонка, страницы входа, карточек и модальных окон.

Файлы Телемоста не модифицируются — стили фонов накладываются в рантайме.

---

## Быстрый старт

### 1. Где указывать настройки
Откройте файл темы:
- Для пользователей exe: `%LOCALAPPDATA%\TelemostThemeOverride\theme.json`
- Для разработчиков: `config/theme.json`

### 2. Простой пример (картинка на фон чата)

Вы можете просто указать путь к локальному файлу на диске или Data URI:

```json
{
  "name": "Custom Theme with Chat Wallpaper",
  "id": "custom-theme",
  "light": {
    "seeds": { ... },
    "backgrounds": {
      "chat": "./wallpapers/light-chat.jpg"
    }
  },
  "dark": {
    "seeds": { ... },
    "backgrounds": {
      "chat": "./wallpapers/dark-chat.jpg"
    }
  }
}
```

---

## Доступные места интерфейса (поверхности)

Вы можете настроить фоновое изображение для любой из следующих зон:

| Ключ | Алиасы | Зона интерфейса | Что покрывает |
| --- | --- | --- | --- |
| `chat` | `conversation` | **Окно переписки / чат** | Область сообщений и активного диалога |
| `page` | `app` | **Главный фон приложения** | Глобальная подложка окна, фон всей страницы |
| `sidebar` | `threads` | **Боковая панель** | Список чатов, папки, боковая навигация |
| `home` | `hub` | **Главный экран / Хаб** | Стартовая страница Телемоста со списком встреч |
| `login` | — | **Страница входа** | Экран авторизации и подключения |
| `call` | `meeting` | **Экран видеозвонка** | Подложка окна конференции и ожидания звонка |
| `modal` | `card`, `popup` | **Модальные окна и карточки** | Всплывающие диалоги, карточки, попапы |
| `settings` | — | **Настройки** | Страница параметров и профиля |
| `custom` | — | **Произвольные элементы** | Массив правил с безопасными CSS-селекторами |

## Форматы источников изображений

1. **Локальные файлы на диске** (рекомендуется):
   - Относительный путь от `theme.json`: `"./wallpaper.png"`, `"images/my_bg.jpg"`
   - Абсолютный путь: `"C:/Users/User/Pictures/background.webp"`
   - *Программа автоматически загружает файл и преобразует его в Base64 Data URI, поэтому картинка отобразится мгновенно и без задержек сети!*
   - Поддерживаемые форматы: `.png`, `.jpg`, `.jpeg`, `.webp`, `.svg`, `.gif`, `.avif`, `.bmp`, `.ico` (тип определяется по содержимому файла).

2. **Data URI (Base64)**:
   - `"data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAA..."`

3. **CSS-градиенты**:
   - `"linear-gradient(135deg, #fce2ec 0%, #fff5f8 100%)"`
   - `"radial-gradient(circle at top, #f4accb 0%, #20121a 100%)"`

*Примечание по безопасности*: Внешние `http(s)://` URL заблокированы в целях конфиденциальности (защита от утечки IP-адреса и факта запуска приложения).

## Параметры настройки фона

Каждая поверхность может быть задана строкой (путь к файлу / Data URI / градиент) или объектом с подробными параметрами:

```json
"chat": {
  "image": "images/chat-art.jpg",
  "size": "cover",
  "position": "center",
  "repeat": "no-repeat",
  "attachment": "fixed",
  "overlay": "rgba(255, 245, 248, 0.82)",
  "blendMode": "normal",
  "opacity": 1.0
}
```

### Описание параметров:

- **`image`** *(обязательно)*: Путь к локальному файлу, Data URI или градиент.
- **`overlay`** *(рекомендуется)*: Полупрозрачный цвет или градиент наложения поверх картинки (например `"rgba(255, 245, 248, 0.85)"` для светлой темы или `"rgba(32, 18, 26, 0.8)"` для тёмной темы). Это лучший способ приглушить фон, чтобы текст сообщений и иконки оставались 100% читаемыми поверх любого арта!
- **`size`**: Масштабирование фона (`"cover"` по умолчанию, `"contain"`, `"auto"`, точные размеры).
- **`position`**: Выравнивание фона (`"center"`, `"top"`, `"bottom"`, `"center top"`, `"right bottom"` и т.д.). По умолчанию `"center"`.
- **`repeat`**: Повторение картинки (`"no-repeat"`, `"repeat"`, `"repeat-x"`, `"repeat-y"`).
- **`attachment`**: Поведение при прокрутке (`"fixed"`, `"scroll"`, `"local"`).
- **`blendMode`**: Режим наложения фона (`"normal"`, `"overlay"`, `"multiply"`, `"screen"`, `"soft-light"`).
- **`opacity`**: Прозрачность всего DOM-элемента контейнера (число от `0.0` до `1.0`). *Внимание: устанавливает `opacity` на весь блок целиком, включая его дочерние элементы и текст. Для полупрозрачности только подложки используйте параметр `overlay`.*

        "position": "center",
        "overlay": "rgba(255, 245, 248, 0.85)"
      },

        "repeat": "repeat",
        "size": "auto",
        "overlay": "rgba(253, 237, 243, 0.9)"

    }

  "dark": {

      "neutral": "#a88697",
      "primary": "#f497be",
      "success": "#10b981",
      "warning": "#fbbf24",

        "size": "cover",
        "position": "center",

      "sidebar": {

    }
  }

### Пример 2. Общие обои для всей темы (на корневом уровне)

Если вы хотите использовать одни и те же картинки в обоих режимах, укажите `backgrounds` на верхнем уровне:

```json
{
  "name": "Universal Theme",
  "id": "universal-theme",
  "backgrounds": {
    "chat": {
      "image": "images/chat-bg.jpg",
      "size": "cover",
      "position": "center",
      "overlay": "rgba(0, 0, 0, 0.3)"
    },
    "page": "images/app-bg.png"
  },
  "light": { "seeds": { ... } },
  "dark": { "seeds": { ... } }
}
```

### Пример 3. Кастомные селекторы (`custom`)

Вы можете повесить фон на абсолютно любой элемент интерфейса Телемоста:

```json
"backgrounds": {
  "custom": [
    {
      "selector": ".yamb-telemost-login-page",
      "image": "images/login-illustration.png",
      "size": "contain",
      "position": "bottom right",
      "repeat": "no-repeat"
    }
  ]
}
```

## Советы для идеального результата

1. **Читаемость текста**: Всегда используйте параметр `overlay` (например `"rgba(255, 245, 248, 0.85)"` в светлой теме или `"rgba(32, 18, 26, 0.8)"` в тёмной), чтобы текст переписки не сливался с пестрыми участками картинки.
2. **Локальные файлы**: Храните файлы картинок рядом с `theme.json` (например в папке `%LOCALAPPDATA%\TelemostThemeOverride\wallpapers\`). При запуске они автоматически встроятся в приложение.
3. **Паттерны и узоры**: Для бесшовных текстур используйте `"repeat": "repeat"` и `"size": "auto"`.
